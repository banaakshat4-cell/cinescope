# 🎬 CineScope

A premium movie discovery website built with **HTML, CSS, and JavaScript**.

CineScope allows users to explore movies, search for specific titles, filter movies by genre, rating and year, and sort results according to their preferences.

## ✨ Features

- 🔍 Movie search functionality
- 🎭 Genre filtering
- ⭐ Rating-based filtering
- 📅 Year-based filtering
- ↕️ Movie sorting
- 🎞️ Movie cards with posters and details
- 📱 Responsive and modern UI
- 🖥️ Clean dark-themed interface
- ⚡ Interactive filtering using JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Movie Database API

## 📂 Project Structure

```text
cinescope/
│
├── index.html
├── style.css
└── script.js
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start exploring movies.

## 🎯 Project Purpose

CineScope was created as a frontend web development project to demonstrate the use of **HTML, CSS, JavaScript, API integration, DOM manipulation, search functionality, filtering, and responsive UI design**.
